# Particle Experiment 7 · AI 脑波版

基于 Shadertoy 着色器 [MddGWN "Particle Experiment 7"](https://www.shadertoy.com/view/MddGWN)（作者 [aiekick](https://www.shadertoy.com/user/aiekick) / Stephane Cuillerdier, 2015）的本地复刻与大幅改编。单文件、零依赖，浏览器双击即开。

**在线体验**：直接下载 `particle-experiment-7.html` 用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开即可，无需服务器、无需联网。

## 功能

- **原版复刻**：metaball 粒子辉光内核与 Shadertoy 兼容运行时（`iTime` / `iResolution` / `iMouse` 等 uniforms），原着色器署名与许可保留在文件内
- **AI 脑波视觉**：电光蓝渐变 + 粉紫突触点缀、脑电波多频段节律（δ/θ/α/β 能量漂移 + 偶发尖峰簇）驱动呼吸与明暗
- **自动形态场景**：变形扩散环 / 粒子线条 / 铺满全屏 / 体块聚散（聚合→打散循环）四种大形态定时平滑切换
- **对话意象生成**：底部输入框输入词语，本地语义引擎分析后"思考"（联想轮换预览）并生成专属动态图形与配色——11 种意象程序：雨丝下坠 / 落雪纷飞 / 烈焰迸发 / 海浪起伏 / 不安战栗 / 心动轮廓 / 星系旋涡 / 静夜星光 / 惊雷炸裂 / 疾风穿行 / 繁花绽放；未收录词汇由文本哈希确定性归类，任何词都有回应
- **拖动轨迹跟随**：普通鼠标移动不影响粒子；**按住拖动**时粒子沿轨迹组成线形拖尾跟随，松手后按寿命自然消散再回归场景
- **交互与调节**：点击移环心、空格暂停、R 重置、双击全屏；右侧参数面板可调粒子数、光晕、场景停留、拖尾、脑波强度、三组颜色等十余项参数

## 技术要点

- WebGL2 优先、WebGL1 自动回退；全屏三角形 + 片段着色器逐粒子 metaball 累积
- 鼠标轨迹环形缓冲（uniform 数组）传入着色器，路径采样与切向计算用于拉伸成丝
- 场景 / 意象 / 拖动三层位置混合架构，uniform 条件分支跳过未激活层以保帧率
- 语义引擎：中英文两百+词根与字级匹配计分，色相 / 饱和 / 脑波参数随意象联动
